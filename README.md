# Geo Analytics Pipeline

## О проекте

ETL-пайплайн для обработки событий социальной сети и построения геоаналитических витрин.

Пайплайн обрабатывает пользовательские события, обогащает их географическими данными и формирует витрины для анализа активности пользователей, географии и рекомендаций друзей.

## Что реализовано

* Реализована обработка пользовательских событий с использованием PySpark.
* Выполнено обогащение событий географическими данными о городах.
* Рассчитан текущий город пользователя и определён город проживания на основе истории перемещений.
* Сформированы показатели путешествий и активности пользователей.
* Реализована агрегация пользовательских событий по географическим зонам.
* Рассчитаны показатели сообщений, реакций, подписок и регистрации пользователей.
* Реализована витрина рекомендаций друзей на основе общей подписки на сообщества и географической близости пользователей.
* Настроена ежедневная обработка данных и формирование витрин в формате Parquet.
* Оркестрация ETL-процесса выполнена с использованием Apache Airflow.

## Логика обработки

Пользовательские события обрабатываются в Spark, обогащаются географическими данными и используются для формирования нескольких аналитических витрин. Airflow управляет последовательностью запуска: сначала формируется пользовательская витрина, после чего параллельно рассчитываются географическая аналитика и рекомендации друзей.

## Ключевые технические решения

### Apache Spark / PySpark

PySpark используется для обработки больших объёмов событий и построения аналитических витрин.

В проекте реализованы:

* географическое обогащение событий;
* расчёт расстояний между координатами;
* определение ближайшего города;
* оконные функции для анализа истории перемещений;
* агрегации пользовательской активности;
* формирование рекомендаций на основе географической близости.

Для эффективной обработки справочника городов используется `broadcast`.

### Apache Airflow

Airflow используется для ежедневной оркестрации ETL-пайплайна.

DAG `geo_analytics_pipeline` запускает три Spark-задачи:

1. формирование пользовательской витрины;
2. формирование географической аналитики;
3. формирование витрины рекомендаций друзей.

После формирования пользовательской витрины две последующие задачи выполняются параллельно.

### Хранение данных

Результаты обработки сохраняются в формате Parquet.

Пайплайн формирует отдельные витрины для:

* пользовательской геоаналитики;
* географической активности;
* рекомендаций друзей.

## Системные требования

* Python 3.9+
* Apache Spark 3.x
* PySpark
* Apache Airflow
* Java, совместимая с используемой версией Spark
* HDFS или совместимое распределённое хранилище

Для запуска необходим доступ к исходным данным и хранилищу, используемому Spark.

## Развёртывание и запуск

1. Клонировать репозиторий.
2. Настроить пути к исходным данным и выходным витринам.
3. Разместить DAG и Spark-скрипты в соответствующих директориях Airflow.
4. Запустить DAG `geo_analytics_pipeline` в Apache Airflow.

## Конфигурация

Пути к исходным данным и аналитическим витринам вынесены в конфигурацию проекта.

Основные параметры включают:

* путь к событиям пользователей;
* путь к справочнику городов;
* пути к пользовательской, географической и рекомендательной витринам.

## Результат

В результате реализован ежедневный batch ETL-пайплайн, который преобразует события социальной сети в набор аналитических геовитрин. Проект демонстрирует применение PySpark для обработки данных, Apache Airflow для оркестрации и построения аналитических витрин в распределённом хранилище.
